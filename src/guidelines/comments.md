# Comments should carry a meaningful message

## Goal

We strive to write code that explains itself. Comments shouldn't be used when
it is logical, when you can infer the logic from it. They should be scarce.

## Why

Comments add up. If you spam with them, there is more code to grasp.

## Instructions

Only explain things that deviate. Better to name function in a bit longer
manner than add a comment about what it does.
